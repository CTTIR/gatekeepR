# Plot state calls for one image

Plot state calls for one image

## Usage

``` r
gk_plot_states(state_calls, image_id)
```

## Arguments

- state_calls:

  A gk_state_calls() result.

- image_id:

  Image to plot.

## Value

A ggplot object.
