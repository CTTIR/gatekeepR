# Plot a threshold density and its evidence pools

Plot a threshold density and its evidence pools

## Usage

``` r
gk_plot_density(thresholds, marker, image_id, parent = NA_character_)
```

## Arguments

- thresholds:

  A gk_thresholds() result.

- marker:

  Marker to plot.

- image_id:

  Image to plot.

- parent:

  Parent set for a state threshold; NA for identity markers.

## Value

A ggplot object.
