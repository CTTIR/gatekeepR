# Make a compact overview

Make a compact overview

## Usage

``` r
gk_plot_overview(x, image_id)
```

## Arguments

- x:

  A prepared, classified or replayed object.

- image_id:

  Image to plot.

## Value

A patchwork object when patchwork is installed, otherwise the map.
