# Plot thresholds for one image

Plot thresholds for one image

## Usage

``` r
gk_plot_thresholds(thresholds, image_id)
```

## Arguments

- thresholds:

  A gk_thresholds() result.

- image_id:

  Image to plot.

## Value

A ggplot object.
