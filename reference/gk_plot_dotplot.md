# Plot marker means by classified cell type

Plot marker means by classified cell type

## Usage

``` r
gk_plot_dotplot(prepared, classification, thresholds)
```

## Arguments

- prepared:

  A gk_prepare() result.

- classification:

  A gk_classify() result.

- thresholds:

  A gk_thresholds() result.

## Value

A ggplot object.
