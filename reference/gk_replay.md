# Replay all effective review decisions

Replay all effective review decisions

## Usage

``` r
gk_replay(review)
```

## Arguments

- review:

  A
  [`gk_review()`](https://github.com/CTTIR/gatekeepR/reference/gk_review.md)
  object.

## Value

A `gk_replayed` object with effective cells, thresholds and state calls.
